## 当前契约约束

- 公共 API 不接收业务请求头；JSON 请求示例只使用协议头 `Content-Type`。
- WebFE 生成内部请求流水，并使用服务器配置的固定 POC 操作员和机构。
- `workDate` 在录入 Body 中必填，在修改 Body 中可选，在通用查询和待复核查询 Query 中可选并默认当前日期。
- 所有响应顶层只包含 `respCode`、`respMsg` 和 `data`，不得出现旧的 `success` 字段。
- 分页统一使用 `pageNo`、`pageSize`、`total` 和 `records`。
- 录入和修改支持可选字段 `payerAddress`、`payeeAddress`、`payerBankName`。
- 修改语义为：未传保留、非空字符串覆盖、空字符串清空。
- 详情返回三个新增字段；通用列表和待复核列表不返回它们。
- 不增加账号、登录、权限、身份校验、数据库部署或额外业务逻辑说明。

## 字段与示例

录入请求表和示例列出当前完整业务字段及必填性、默认值和限制。修改接口说明可编辑范围与新增三字段的清空语义。详情示例展示完整单据字段，列表示例只展示现有列表字段。

所有示例使用一致的日期、流水号、金额和状态，确保一套示例可串联为完整联调流程。
